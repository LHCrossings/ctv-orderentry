S3 Cleanup

Program assets marked expired in Etere that still hold a file in S3. The same thing as Etere's "Delete on → AWS S3" workflow, in batches instead of one Datamover job per file. Commercials, PSAs, PIs, station IDs, bumpers, opens and anything marked HIATUS are never touched.

The scan reads Etere and checks each file in S3 without touching it (about 40 seconds). Nothing is deleted until you pick groups and confirm.
